# UE5 完整消息号对照表

本文档用于 UE5 客户端与当前游戏服务端进行协议对接时，快速查阅消息号、方向、用途和建议处理位置。

> 说明：
> - 部分消息号在当前 MVP 阶段存在“请求/响应共用”或“预留复用”的情况。
> - 蓝图层建议只调用封装好的 C++ 接口，不直接处理 socket。
> - 消息号与 protobuf 类型请以服务端 `shared-proto` 为准。

---

# 1. 认证与登录

| MsgId | 方向 | 含义 | 建议处理 |
| --- | --- | --- | --- |
| `1001` | C -> S | 握手请求 | `UGameNetworkSubsystem::SendHandshake()` |
| `1002` | S -> C | 握手响应 | C++ 处理后广播蓝图事件 |
| `2001` | C -> S | 角色列表请求 | 登录后进入角色选择页触发 |
| `2002` | S -> C | 角色列表响应 / 创建角色确认 | 角色选择页刷新列表 |
| `2003` | C -> S | 创建角色请求 / 进入角色请求（当前实现中可能复用） | 角色选择页 |
| `2004` | S -> C | 创建角色响应 / 进入角色响应 | 角色选择页 / 场景进入前 |

# 13. UE5 蓝图接入优先级建议

## 第一阶段
- `1001` 握手
- `2001/2002/2004` 角色列表与进入
- `4001/4002` 进场景
- `3001/3002/3003` 心跳与移动

## 第二阶段
- `7001/7003` 聊天
- `5001/5003` 战斗
- `6002/6003` 掉落与拾取
- `10001/10002/10003` 背包/装备

## 第三阶段
- `9001~9004` 任务
- `11001~11005` 队伍
- `12001~12005` 副本
- `13001~13006` 宠物
- `14001~14004` 强化

# 14. 实施建议

建议 UE 程序员在代码中定义统一枚举：

```cpp
enum class EGameMsgId : int32
{
    HandshakeReq = 1001,
    HandshakeRes = 1002,
    CharacterListReq = 2001,
    CharacterListRes = 2002,
    CreateCharacterReq = 2003,
    CreateCharacterRes = 2004,
    HeartbeatReq = 3001,
    HeartbeatRes = 3002,
    MoveRes = 3003,
    EnterSceneReq = 4001,
    EnterSceneRes = 4002,
    AttackReq = 5001,
    AttackRes = 5002,
    DamageEvent = 5003,
    // ...
};
```

这样蓝图和 C++ 都能按同一套编号工作。
